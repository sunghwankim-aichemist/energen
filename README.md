# 에너젠 웹ERP 데모

에너젠 로고의 남색 `#1C287B`와 적색 `#AF1E24`를 적용한 제조·품질 통합관리 데모입니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 엽니다. 별도 설치·빌드 없이 실행할 수 있습니다.

## 기능

- 통합 대시보드와 프로젝트 등록
- 제조지식 질의와 카탈로그 근거 확인
- 준비문서 초안, 검토·승인·보완, 개정본 생성
- 생산 공정 기록 및 품질 검사·재검사
- 기술보고·회의록, A/S 이력
- 활동 로그 및 JSON·CSV 내보내기

## 데이터와 제한

모든 프로젝트·실적은 예시입니다. 업무 데이터는 브라우저의 localStorage에 저장되며, 기기 간 공유되지 않습니다. AI 응답은 준비된 근거·템플릿 기반 시연입니다. 실제 LLM, ERP·NAS, 업무상 로그인·권한, 전자서명은 연결되지 않았습니다. 실제 기술판정 또는 공식 결재 용도로 사용할 수 없습니다.

로고, 카탈로그 발췌본, 업무흐름도는 제공된 참조자료입니다. 공개 저장소 전환이나 외부 재배포 시 해당 자료의 공개 범위를 확인해야 합니다.

## 파일 구성

- `index.html`, `style.css`, `app.js`: 실행용 화면·스타일·업무 로직
- 로고·카탈로그 발췌본·업무 흐름도: 참조자료
- `check.cjs`: 주요 업무 상태 전환 검증
- `.gitignore`: 로컬 설정·인증정보 등의 업로드 제외

## 검증

Node.js가 설치된 환경에서 프로젝트 폴더에서 `node check.cjs`를 실행합니다. 주요 업무 상태 전환을 코드 수준에서 검증하며, 브라우저 시각 검증을 대체하지 않습니다.

## 화면 반영 사항

원본 로고 2종과 에너젠 브랜드 색상을 적용했습니다. 헤더 로고는 제거했고 헤더는 스크롤 중 상단에 유지됩니다.
